Capture the page you are reading

Install the browser extension

Development preview · extension version 0.1.2

The extension saves a rendered webpage and available images into your local PostKeeper library. A fresh install opens keep.fishese.cc by default. You can change the destination later in the extension's connection settings.

Updating preserves a destination you previously saved. If an older setup still points to localhost, change Connection settings → PostKeeper PWA URL to https://keep.fishese.cc/ and save.

These downloads are developer packages. Chromium requires Developer mode, and the unsigned Firefox build is temporary. Store-signed installation is not available yet.

Recommended on desktop

Chrome and Chromium-based browsers

Download Chromium ZIP
  1. Download the ZIP and extract it to a folder you will keep.
  2. Open chrome://extensions in Chrome, or the equivalent extensions page in your Chromium browser.
  3. Turn on Developer mode, then choose Load unpacked.
  4. Select the extracted folder that contains manifest.json.
  5. Pin PostKeeper to the toolbar, open a webpage, and choose Save current page.
  6. Approve the connection permission for https://keep.fishese.cc. PostKeeper opens and confirms the import after it is stored locally.

See Google's official Load unpacked instructions. Official Chrome for Android does not install desktop Chrome extensions.

Temporary developer install

Firefox desktop

Download Firefox ZIP
  1. Download the ZIP.
  2. Open about:debugging, then choose This Firefox.
  3. Choose Load Temporary Add-on and select the downloaded ZIP.
  4. Use the PostKeeper toolbar button and approve the PWA connection permission when asked.

Firefox removes this temporary add-on when the browser restarts. Standard Firefox requires Mozilla to sign persistent add-ons. See Mozilla's temporary installation guide and signing explanation.

Android and the PostKeeper APK

Browser extension on Android

PostKeeper has passed compatibility tests in extension-capable Android browsers, but there is no supported public phone installer in this preview. The desktop ZIP steps above do not apply to official Chrome for Android.

PostKeeper APK

A browser extension cannot send directly into the APK's private WebView library. In the APK, share a link to PostKeeper or use its isolated capture browser. To move saved items between the web/PWA library and APK library, export a portable backup and import it on the other side.
